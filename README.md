# Onda

**Sound, in harmony.**

Official downloads, setup information and community support for Onda for Mac and Onda Room for iPhone. Application source is maintained separately in a private repository. This repository contains no user room maps, recordings or pairing credentials.

- [Website, compatibility and setup](https://onda-sound.sam633419.chatgpt.site)
- [Mac downloads](https://github.com/SomaSam38/onda-releases/releases)
- [Support](https://onda-sound.sam633419.chatgpt.site/support/)
- [Privacy policy](https://onda-sound.sam633419.chatgpt.site/privacy/)

The Mac app is a signed and Apple-notarized direct download. It includes the local audio driver and runs on compatible Apple silicon and Intel Macs. macOS 14+; optional Spotify sharing requires 14.2+.

Onda Room is being prepared for the iPhone App Store and is **not live yet**. Camera mapping requires LiDAR. Measured room EQ/sync currently supports the original two-eight-channel-Studio-Display topology; generic speaker combinations use estimated/manual timing and personal tone controls.

Please use the issue templates for help or feedback. Reports are public and require a GitHub account. Never post pairing keys, passwords, recordings, room maps or private device/network information. There is no guaranteed response time.
